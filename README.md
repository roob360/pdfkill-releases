# PDFKill

Pembaca dan penyunting PDF untuk Windows dengan mode Baca, Edit, dan Engineering (takeoff gambar kerja).

**Unduh:** halaman [Rilis](../../releases/latest) atau situs unduh repo ini.

Repo ini hanya berisi berkas rilis (installer dan berkas pembaruan). Kode sumber tidak dipublikasikan.

Berlisensi Apache-2.0 (lihat `LICENSE`). Daftar lisensi pustaka pihak ketiga ada di aplikasi: menu utama > Tentang PDFKill > Lisensi pihak ketiga.
